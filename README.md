# 星历 · 紫微排盘

一个独立实现的本地紫微斗数排盘网页 MVP，不复制文墨天机的专有代码、品牌素材或页面资源。

- 使用说明：[`使用说明.md`](./使用说明.md)
- Windows x64 安装包：在 GitHub 项目的 Releases 下载；安装器作为 Release 附件提供，不放在普通 Git 历史中。

## 本机开发

```bash
npm install
npm run dev
```

构建检查：`npm run build`

## Windows 安装包

在 Windows x64 电脑上运行：

```bash
npm install
npm run dist:win
```

安装器会生成在 `release/` 目录，文件名为 `星历紫微排盘-1.0.0-Setup.exe`。安装后可从桌面快捷方式或开始菜单启动；应用直接读取本地打包的页面，不需要运行开发服务器。

## 当前功能

- 输入公历生日、时辰、性别并生成命盘
- 展示十二宫与星曜；选择宫位查看主星、辅曜和四化
- 切换流年年份与大限选项
- 浏览器本地计算、打印导出、桌面与窄屏适配
- Electron 桌面壳和 Windows x64 NSIS 安装器

排盘核心使用 MIT 许可的 `iztro` 开源库。当前大限选择器会更新命盘中心标注，但尚未将每个大限选择与整盘星曜完全联动；欢迎提供具体流派、截图或对照生日，继续校验布局及算法设置。命理内容仅供传统文化兴趣研究。
